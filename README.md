# ✨ RarityGlow

<details>
<summary><b>English</b></summary>

RarityGlow adds a **colored glow** and **3D beam pillar** to items on the ground, based on their rarity.

| Rarity   | Glow Color | Default Beam |
|----------|------------|--------------|
| Common   | White      | ❌ Off        |
| Uncommon | Yellow     | ✅ On         |
| Rare     | Cyan       | ✅ On         |
| Epic     | Magenta    | ✅ On         |

### Features
- 🌟 **Colored outline glow** — highlights dropped items by rarity
- 🏛️ **3D beam pillar** — a vertical light pillar rising from items (with smooth fade and taper)
- 🎨 **Fully customizable** — all colors, beam height/width/offset, and render distance are adjustable
- 🔘 **Per-rarity toggles** — enable/disable glow and beam independently for each rarity
- 🔧 **ModMenu support** — all settings available through the config screen

### Requirements
- Fabric API
- Cloth Config

</details>

<details>
<summary><b>中文</b></summary>

RarityGlow 为掉落物添加**稀有度彩色发光**和**3D 光柱**特效。

| 稀有度 | 发光颜色 | 默认光柱 |
|-----|------|------|
| 普通  | 白色   | ❌ 关闭 |
| 罕见  | 黄色   | ✅ 开启 |
| 稀有  | 青色   | ✅ 开启 |
| 史诗  | 品红   | ✅ 开启 |

### 特性
- 🌟 **彩色轮廓发光** — 按稀有度高亮掉落物
- 🏛️ **3D 立体光柱** — 从物品升起的光柱，渐变透明且逐渐收细
- 🎨 **完全自定义** — 所有颜色、光柱高度/粗细/偏移/渲染距离均可调整
- 🔘 **独立开关** — 发光和光柱对每种稀有度可分别开关
- 🔧 **ModMenu 支持** — 所有设置在配置界面中调整

### 依赖
- Fabric API
- Cloth Config

</details>
